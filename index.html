LabTest — Laboratório de Testes

Ambiente didático para planejar casos, executar testes, registrar defeitos e analisar resultados. Loja e dados totalmente fictícios.

Bem-vindo ao laboratório

Você é responsável por testar uma loja virtual fictícia. Leia os requisitos, execute os casos de teste e registre o que observou. Alguns comportamentos incorretos foram inseridos intencionalmente para fins educacionais.

Informação: não use senhas reais nem dados pessoais. Os registros são salvos automaticamente neste navegador, separados por nome e turma. Eles não são enviados para um servidor.

Identificação do aluno

Preencha seu nome e turma antes de começar. Os registros serão salvos automaticamente neste navegador, separados por nome e turma.

Identifique-se para iniciar.

Requisitos básicos da loja

  1. Usuários devem informar e-mail e senha para entrar.
  2. É possível pesquisar produtos existentes.
  3. Produtos podem ser adicionados ao carrinho.
  4. A quantidade de cada produto deve ser maior que zero.
  5. O pedido exige endereço de entrega.
  6. O sistema deve apresentar confirmação após finalizar o pedido.

Roteiro sugerido

  1. Abra a Loja virtual e explore as funções.
  2. Na Lista de testes, execute os casos e compare o comportamento com o esperado.
  3. Marque cada caso como aprovado ou reprovado e registre suas observações.
  4. Se marcar um caso como REPROVADO, registre o defeito correspondente na área Registro de defeitos. Isso documenta o que falhou e como outra pessoa pode reproduzir o problema.
  5. Use o relatório para responder à atividade solicitada pelo professor.

Arquivo de entrega

O relatório HTML é o único arquivo que você precisa baixar e entregar. Ele reúne sua identificação, os doze resultados, observações, defeitos registrados e data de finalização. Você pode abrir o arquivo HTML no navegador e imprimir ou salvar como PDF, se necessário.

Manutenção da atividade

Use esta opção somente se precisar apagar todos os registros desta atividade e começar novamente. Essa ação remove a identificação salva, os resultados dos testes, as observações e os defeitos deste navegador. Ela não pode ser desfeita.
